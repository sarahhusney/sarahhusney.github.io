The challenge

A site that grew page by page.

Over time the site had collected inconsistent layouts, sidebars that squeezed content, long all-caps text, an auto-rotating carousel, and navigation organized around departments instead of the people looking for answers.

The approach

Three principles.

01

Start with the visitor

Navigation and page structure built around who's visiting: prospective and current students, researchers, alumni, and donors.

02

One system, every page

Reusable banners, cards, buttons, and resource links, so all 175 pages look and behave consistently and are easier to maintain.

03

Accessible by default

Sentence case instead of all caps, no auto-rotating content, clear button labels, and full-width layouts that work on phones.
